# 株シミュ — 株式投資シミュレーションAndroidアプリ

実際の株価（Yahoo!ファイナンス由来・15〜20分遅延）を使って、**架空の資金**で株式投資を体験できるシミュレーションゲームです。実際のお金は一切動きません。

## 遊び方

1. **初回起動時に初期資金を設定**（プリセット100万〜1,000万円、またはカスタム金額）
2. **検索タブ**で銘柄を探す（銘柄名でもコードでもOK。例:「トヨタ」「7203」）
3. 銘柄詳細画面でチャートを確認して**「買う」「売る」**
4. ポートフォリオ画面で総資産・評価損益を管理
5. 総資産が尽きたら**ゲームオーバー**。何度でもやり直せます

## 主な機能

- **リアル株価**: Yahoo Finance の公開エンドポイント（`query1.finance.yahoo.com`）から取得。約15〜20分遅延のデータです
- **対象銘柄**: 東証上場の株式・ETF（円建てで完結させるため `.T` 銘柄に限定）
- **チャート**: 1日/1週/1ヶ月/6ヶ月/1年の折れ線チャート。横ドラッグで日時・価格を確認できるクロスヘア付き
- **証券アプリ風UI**: 常時ダークテーマ。騰落は日本の慣習に合わせ**赤=上昇/緑=下落**（▲▼記号併記で色弱の方にも判別可能）
- **売買手数料**: 約定代金の0.1%（シミュレーションのリアリティ用）
- **自動更新**: ポートフォリオの株価は60秒ごとに自動リフレッシュ
- **永続化**: 資金・保有銘柄・取引履歴は Room データベースに保存

## 技術構成

| 項目 | 内容 |
|---|---|
| 言語 / UI | Kotlin / Jetpack Compose (Material 3) |
| アーキテクチャ | MVVM + Repository（手動DI） |
| ローカルDB | Room（資金・保有銘柄・取引履歴） |
| 通信 | OkHttp + kotlinx.serialization |
| ナビゲーション | Navigation Compose（資産/検索/履歴 + 銘柄詳細） |
| minSdk / targetSdk | 26 / 35 |

## ビルド方法

Android Studio（Ladybug 以降推奨）でこのリポジトリを開き、そのまま Run してください。コマンドラインの場合:

```bash
./gradlew assembleDebug
# APK: app/build/outputs/apk/debug/app-debug.apk
```

※ このリポジトリには Gradle Wrapper の設定を含めています。初回ビルド時に依存関係と Android SDK コンポーネントのダウンロードが必要です。

## 注意事項

- Yahoo Finance のエンドポイントは**非公式**の公開APIです。仕様変更やレート制限（HTTP 429）で取得できなくなる可能性があります。その場合は時間を置くか、`YahooFinanceClient.kt` のエンドポイントを見直してください
- 本アプリは教育・娯楽目的のシミュレーターであり、投資助言ではありません
